# 🌍 Nomad Journey — Frontend Project

A travel journaling and discovery web application built with React JS. Nomad Journey lets users document their travels, explore destinations on an interactive map, and connect with other nomads through rich, community-driven content.

---

## ✨ Features

- **Interactive Maps** — Explore and pin destinations using Leaflet.js
- **Rich Text Journaling** — Write detailed travel stories with a Quill.js editor
- **Autocomplete Search** — Quickly find cities and places with smart suggestions
- **User Profiles** — Letter-based avatars and personalised profile pages
- **Local Storage Persistence** — Session data retained across page reloads
- **REST API Integration** — Communicates with a dedicated backend via the Fetch API
- **Responsive UI** — Material UI components with custom Tailwind CSS styling
- **Async/Await Throughout** — Clean asynchronous data fetching and state updates

---

## 🛠️ Tech Stack

| Category | Technology |
|---|---|
| Framework | React 18 |
| Build Tool | Vite |
| Styling | Tailwind CSS + Material UI |
| Maps | Leaflet.js |
| Rich Text | Quill.js |
| HTTP | Fetch API |
| State | React Hooks + Local Storage |
| Language | JavaScript (ES2017+) |

## 🚀 Getting Started

### Prerequisites

- Node.js ≥ 16
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/ByteBuilderSs/Nomad-Journey-Frontend.git
cd Nomad-Journey-Frontend

# Install dependencies
npm install
```
